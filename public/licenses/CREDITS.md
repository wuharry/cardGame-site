## 本專案生成、製作與第三方衍生

原創程序音效位於 `assets/audio/sfx/original/` 與 `assets/audio/ambience/original/`：開包分級、暗系／奧術、勝敗短樂句、合成弦釋放、洞穴底聲與滴水，由 synthesize_audio_gap_fill.py 製作。這些音效未使用第三方錄音；洞穴與弦聲是合成設計，並非實地錄音。來源、生成 seed 與測量記錄見 SOURCES.json。

本專案產出的檔案不一定全是原創：從第三方素材裁切、重繪或烘焙而來的輸出，仍保留基底作者與授權。

## 遊戲內掛名

玩家下載後可能不會再回到 itch.io 頁面，所以同一份文字在遊戲裡也要看得到：
主選單 →「製作群」。顯示文字的唯一來源是 src/ui/credits_text.gd
（寫在腳本常數而不是 .txt，因為 `export_presets.cfg` 的 `include_filter` 是空的，
純文字檔不會被打包進匯出版）。

本檔與該檔**必須同步**，`tests/credits_text_test.gd` 會比對兩邊的作者名，只改一邊會失敗：

```bash
godot --headless --path . -s tests/credits_text_test.gd
godot --path . -s tests/screenshot_credits.gd -- <絕對路徑.png> [en]   # 版面目視
```

## 維護方式

資料夾有增減時，用這條確認沒有漏列：

```bash
find assets -maxdepth 2 -type d | sort     # 對照本檔各區是否都涵蓋到
find assets -iname 'LICENSE*' -o -iname '*readme*'   # 找出附帶授權檔的素材
```

2026-10-06 的掃描刪除了兩個空資料夾（`assets/environment/stylized_nature`、`assets/water/sea_water_material`），兩者皆無檔案也無程式引用。
