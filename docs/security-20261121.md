## 介面與版本

- 統計預設直接顯示分子、分母和少量樣本，不再把缺少存活資料解讀為上場即死。提醒改為待查原因，避免以回收率等單一指標斷言設計好壞。
- 散佈圖支援選單、方向鍵及精確數值讀取；重疊點也能逐張選取。縱軸依實際事件比率延伸，避免超過 100% 的數值被裁切。
- 篩選有「尚未套用」與還原狀態；背景分頁恢復可見時補載入。空資料與無符合搜尋結果分開顯示。手機表格可以完整橫向閱讀。
- 官網下載連結會移動鍵盤焦點、避開固定頁首；手機選單在 Escape、選擇連結或焦點離開時關閉，圖示改用一致的向量線條。
- 修復 lockfile 漏列的可選轉接依賴。乾淨安裝後 Next 實際版本為 **16.4.6**，與 package.json、eslint-config-next 一致；修復前本機仍殘留 16.4.2，正式建置會被安全版本檢查擋下。

Next 官方的 [11 月安全更新](https://nextjs.org/blog/november-2026-security-release)列出修正版 16.4.5；本案使用後續的 [16.4.6](https://github.com/vercel/next.js/releases/tag/v16.4.6)。

全依賴掃描另找出開發工具鏈的 minimatch 與 Zod 公告（含相依套件共 8 項）；使用不跨越既有直接依賴限制的 `npm audit fix --ignore-scripts --no-fund` 更新後回報 **0 vulnerabilities**。對應公告：[minimatch](https://github.com/advisories/GHSA-g3hv-75wg-m249)、[Zod](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5)。這是當次套件資料庫結果，不是應用程式安全保證。
